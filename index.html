1. Диафрагмальное дыхание + наклон таза

Лягте на спину, колени согнуты. На выдохе подтягивайте низ живота и прижимайте поясницу к полу.

▶ Открыть / скачать видео

2. Скольжение пяток

На выдохе скользите пяткой вперёд. Живот плоский, поясница прижата.

▶ Открыть / скачать видео

3. Ягодичный мостик

На выдохе поднимайте таз, сжимая ягодицы. Без сильного прогиба.

▶ Открыть / скачать видео

4. Кошка-корова

На четвереньках: выдох — округлить спину, вдох — мягкий прогиб.

▶ Открыть / скачать видео

5. Боковые «ракушки»

Лёжа на боку, поднимайте верхнее колено, не вращая таз.

▶ Открыть / скачать видео

6. Мёртвый жук

Опускайте противоположные руку и ногу. Живот остаётся плоским.

▶ Открыть / скачать видео

Рекомендации

  • 2–3 круга, 3–5 раз в неделю
  • Качество важнее количества
  • При «куполе» на животе уменьшайте амплитуду
  • Вставайте с пола через бок
